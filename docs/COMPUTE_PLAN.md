# Compute Plan

The aggregate table and figure rebuild is lightweight and can run on a standard laptop. Rebuilding the full individual-level analysis requires local access to CHARLS files and enough memory to read and harmonize repeated survey modules.

Expected runtime on a recent laptop:

- Official source extraction: under 5 minutes.
- CHARLS harmonization and linkage: 10-30 minutes, depending on disk speed.
- Model and sensitivity analyses: 10-30 minutes.
- Table and figure generation: under 10 minutes.

No cloud computing is required for the province-year analysis.
