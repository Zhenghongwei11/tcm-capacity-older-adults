# Statistical Decision Rules

The primary estimand is the percentage-point difference in individual TCM treatment-use probability per 1-SD higher province-year TCM service-resource density. Standardization uses the 112 linked province-year units represented in the age-eligible CHARLS outcome panel.

Primary models use linear probability models with province and survey-year fixed effects and province-clustered standard errors. The primary bed-density model is accompanied by null-imposed wild-cluster bootstrap inference with Webb six-point weights and 9,999 repetitions because inference is based on 28 province clusters.

Main sensitivity checks include respondent weighting, individual fixed effects, correlated-effects models, province-specific linear trends, lagged supply, leave-one-province-out estimation, province resampling, contextual adjustment for general hospital capacity and provincial socioeconomic conditions, component deletion, broader-utilization specificity checks, and formal interaction testing.

Formal interaction P values for the prespecified access- and need-related family are adjusted with the Holm procedure. Clinically defined multimorbidity phenotype analyses are treated as exploratory extensions of the need-related heterogeneity analysis. Estimates are reported as percentage-point differences with 95% confidence intervals unless otherwise stated.

Figures and tables are rounded for presentation; model source tables retain additional decimal precision.
